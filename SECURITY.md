# Security policy

Please do not open a public issue for a vulnerability.

Report it privately with GitHub private vulnerability reporting on the affected repository. Use the Security tab, then Report a vulnerability.

I am the solo maintainer. AMW is Preview and pre revenue, so response times may vary. I aim to acknowledge a report within five business days and to share a first assessment or a request for more detail within ten business days. These are targets, not promises.

This policy covers the public repositories in this organization. Supported: the latest release of each repository. Older releases get fixes at my discretion.

I credit reporters in release notes unless you ask me not to.

There is no security bounty.
