# Welcome to AMW Preview

Hello. I maintain Agent Middleware (AMW). It is Preview, pre revenue, and I am the solo maintainer.

The gateway source is public under a Fair Source license (FSL-1.1-ALv2). It is source available. The spec, verifier, SDKs, integrations and examples are Apache 2.0.

A retry with the same key returns the original receipt ID. That is not a promise that a remote tool runs only once or that a charge happens only once. A remote tool call that fails before dispatch is refunded and its reserved budget is released. If a crash happens after the remote effect, the reconciler later records a delivery_uncertain receipt ID for that call. A crash on a local in process tool can leave a charged record for manual review with no receipt ID.
