# Contributing

Thanks for helping improve Agent Middleware.

## Before you start

- Open an issue first for large changes so we can align on approach.
- For security issues, follow [SECURITY.md](SECURITY.md). Do not open a public issue.

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Keep the PR small and focused on one change.
3. Run that repository's tests and linters before opening the PR.
4. Open a pull request against `main`.

PRs are squash-merged.
